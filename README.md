# N4 단어 트레이너

JLPT N4 の出題範囲 1000 語を韓国語訳で出題する単語学習アプリ。HTML 1ファイルで動き、ビルドも依存ライブラリも不要です。

## 使い方

`index.html` をブラウザで開くだけです。GitHub Pages を有効にすれば、そのまま公開 URL として使えます。

## 出題モード

| モード | 出題内容 |
| --- | --- |
| 일본어 → 뜻 | 日本語の単語を見て韓国語訳を4択で選ぶ |
| 뜻 → 일본어 | 韓国語訳を見て日本語の単語を4択で選ぶ |
| 한자 읽기 | 漢字の読みを4択、または ひらがなで直接入力 |
| 섞어서 | 上記3モードをランダムに出題 |

誤答の選択肢は同じ品詞から選ぶため、消去法では当たりにくくなっています。読みの問題では、モーラ数が近い読みを誤答に使います。

## 収録語

| 区分 | 語数 |
| --- | --- |
| N4 レベル | 580 |
| N5 レベル（基礎） | 420 |
| **合計** | **1000** |

品詞の内訳は 名詞 539 / 動詞 266 / い形容詞 82 / 副詞・接続詞 72 / な形容詞 41。
うち漢字を含む 872 語が「한자 읽기」モードの出題対象です。

N4 の試験範囲は N5 の語彙を含むため、N5 の基礎語も収録しています。ホーム画面の「레벨」で N4 のみ・N5 のみに絞り込めます。

## 学習記録

単語ごとの正誤を記録し、ホーム画面に「외운 단어（2回連続正解）」「약한 단어（間違えてまだ正解し直していない）」を集計します。「약한 단어만 출제」で苦手な語だけを復習できます。

記録はブラウザの localStorage に保存されます。**端末やブラウザをまたいで引き継がれず、複数人で使っても共有されません。** 端末間で同期したい場合は保存先をサーバー側に変える必要があります。

## 単語の追加・修正

単語データは `index.html` 内の `RAW` と `RAW2` の2つの配列にあります。形式は次のとおりです。

```js
["静か", "しずか", "조용함", "na", "5"]
//  表記    読み      韓国語訳   品詞   レベル
```

- 品詞: `v`（動詞） / `i`（い形容詞） / `na`（な形容詞） / `n`（名詞） / `adv`（副詞・接続詞）
- レベル: `"4"`（N4） / `"5"`（N5）

配列の末尾に追記すれば、そのまま出題対象に加わります。韓国語訳が他の語と完全に一致すると4択で正解が2つになるため、訳は重複しないようにしてください。

## 注意

韓国語訳は市販の単語帳と1語ずつ照合したものではありません。不自然な訳を見つけた場合は修正してください。
